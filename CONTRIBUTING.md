# 🤝 Contributing to RiGallery-NEVAR

## 🛠️ Improve the project

Pull requests are welcome. Describe the problem or improvement and how you verified the change. 

This repository is a fork of [fast4x/RiGallery](https://github.com/fast4x/RiGallery). Use this repository for fork-specific changes and the upstream project for general changes.

## 📜 Clone the repo

    git clone -b main --single-branch --recursive https://github.com/NEVARLeVrai/RiGallery-NEVAR.git

## ✅ Verify your changes

Use a test media library and verify gallery changes on an Android device or emulator.

## 📬 Open a pull request

Keep the change focused and link the related issue when there is one. Include verification steps and screenshots for visual changes when applicable.
